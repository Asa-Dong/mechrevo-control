# 键盘亮度验证

对照参考 TUXEDO v4.25.0_rc 的 uniwill_write_kbd_bl_brightness，实现了固定机型、固定亮度寄存器的短暂诊断。未加载整套 TUXEDO 驱动。

## 结果

- 初始 0x078C=0x80，对应亮度 4/4。
- 0x0741 从 0x80 临时改为 0x81。
- 设置亮度 3，3 秒后读回 0x078C=0x60，确认亮度字段为 3。
- 恢复后 0x078C=0x80、0x0741=0x80，确认亮度 4 和初始控制位。
- 卸载后再运行独立只读探测，确认恢复；两个模块均已卸载。
- 未写 RGB 颜色、风扇、CPU/GPU 功耗或充电配置。

原始日志：`keyboard-brightness-2026-11-09.log`。

## 验证边界

亮度 4→3→4 的寄存器写入、读回和恢复通过；肉眼灯光变化尚待用户确认。未测试所有亮度档、关闭/开启、颜色改变、重启保持或按键联动。当前结论不扩大为“全部 RGB 功能已验证”。Zig 服务仍保持只读。
