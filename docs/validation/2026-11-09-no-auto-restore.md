# 取消主动还原（驱动 0.4.8 / 扩展 17）

按用户要求，取消服务正常退出、驱动卸载、重启/关机通知、睡眠前的主动还原。恢复只在显式 `control=release` 时执行；写入错误停止继续下发并报告错误，不再全量回滚或后台重试。未增加磁盘保存、开机重放、BIOS Flash 写入。

驱动初始化和睡眠恢复读取 EC 风扇 PWM、温区表和曲线启用位。没有可识别曲线表时返回不可用，只有用户主动选择曲线模式才创建默认模板。新驱动加载后既有控制位显示 retained，用户下一次操作可重新接管。手动 PWM 循环在卸载/睡眠时停止，恢复只读取，不自动续发。

“恢复默认值”保留原有的接管前基线语义（不是 BIOS 出厂重置），并切回固件自动风扇。原生模式位为 0 的遗留自定义曲线以办公模式作为显式恢复的回退。

验证：
- Zig 单元测试、只读会话 D-Bus 冒烟测试通过。
- 当前内核 W=1 模块编译通过；DKMS 已安装到 6.12.116+deb13-amd64 和 6.19.13+deb13-amd64，当前运行 0.4.8。
- tests/lifecycle-unit.py 提取实际 C 回调，在模拟 EC 上验证睡眠、恢复、重启通知、卸载均不写寄存器，读取失败不伪造默认值，保留的曲线/控制位可以重新接管。
- tests/lifecycle-hardware.py 分别在自动风扇和有效自定义曲线下通过。切换充电配置后停止服务，设置仍在；卸载/重载驱动后重新读到相同的性能、亮度、RGB、充电、风扇模式和曲线；再次接管和显式恢复通过。
- 实机结束状态：办公、自动风扇、亮度 4、RGB 0/50/50、固定使用，last_error=0。测试留下的有效曲线表为两路 30/40/60/80/100，当前不启用。

没有执行整机重启、断电或实际睡眠。跨重启是否保留由固件决定，尚待用户后续验证。no-restore-before-reboot-2026-11-09.json 是只读对比记录，不会被服务读取或重放。此前验证文档中的自动还原行为仅描述旧版本。
