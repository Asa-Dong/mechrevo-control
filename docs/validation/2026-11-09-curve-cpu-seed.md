# 曲线应用时一次性同步 CPU PWM

> 后续更正：用户确认曲线模式等待更久可以停转，之前的短时观察不能证明存在固定 25% 下限。CPU 一次性 PWM 同步已按用户要求撤回。以下保留当时的测试记录，不代表当前实现。


按用户选择仅处理 CPU，GPU 保持 EC 自主控制。曲线启用并检查门控成功后，读取 CPU EC 温度 0x043e，按图表节点匹配目标，向 0x1804 写一次百分比×2。没有新增温控定时任务。相同曲线再次应用时也同步一次；已处于曲线模式时重复选择曲线仍为无操作。

20–110°C 之外的温度读数跳过同步；EC 读取或 PWM 写入失败上报错误。小于 40°C 请求 0%，40/50/60/70/80°C 起使用对应节点。

验证：实际驱动函数的单元测试覆盖温区边界、无效温度、读取失败、单次 CPU 写入计数以及 GPU 零写入。当前内核构建、签名安装和重载通过。实机 CPU 62°C，原曲线 `0 0 37 57 100`，应用后实际 PWM 37%，CPU 约 2190 RPM；GPU 仍为 0%。重新应用相同曲线成功，last_error=0。

这只同步曲线应用时的初始状态，不保证之后自然降温进入零档时固件一定停转；尚未完成自然温度跨档验证。实机此次验证的是 37% 档，零值写入及边界由单元测试覆盖。
