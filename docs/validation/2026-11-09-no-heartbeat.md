# 0.4.0：取消心跳与超时回收

按用户要求，Zig 不再发送 20 秒 keepalive；内核取消 120 秒租约和手动风扇的租约检查。control 仅接受 acquire / release。失败恢复重试独立保留，不再触发正常会话超时。

设置保持到显式释放或恢复路径执行。正常停止系统服务（包括异常重启后的服务）、模块卸载、休眠及关机通知仍尝试恢复；强制终止服务不再自动恢复。手动风扇仍由内核刷新并做高温保护；曲线由 EC 自主执行。取消心跳不等于跨重启永久保存。

GNOME v7 更多信息仅保留主要温度、简短充电配置与验证状态、控制状态及恢复入口，删除全部传感器罗列、曲线参数和协议说明。

验证记录：curve-persistence-2026-11-09.log、manual-persistence-2026-11-09.log。测试停止 Zig，持续超过 120 秒观察控制模式，然后显式恢复。历史 lease 验证记录仅适用于旧版，不再描述当前行为。

结果：曲线和手动模式均通过无服务、无心跳持续超过旧超时时间及显式恢复检查。Zig 单元测试通过；驱动 0.4.0 已安装四个内核并在当前内核运行。菜单 v7 已安装；独立 Shell 中按钮、滑条、更多信息展开和写入前后菜单高度一致均通过。反馈行设置固定最小高度，并保留控件写入期间的颜色，避免布局跳动和整组变暗。真实桌面需重新登录加载新版扩展。
