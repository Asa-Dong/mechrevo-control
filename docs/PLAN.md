# 后续验证事项

当前实现与使用说明以 [README](../README.md) 和 [驱动文档](../driver/README.md) 为准。

- 逐项验证充电、灯光、性能模式及曲线在正常重启、冷启动、断电后的保留情况。
- 验证实际睡眠/恢复；当前生命周期回调已有模拟测试，不能等同于实机通过。
- 在合适电量条件下验证充电配置的实际效果。
- 用可比较负载测量三档性能/功耗差异。
- 补充长时间运行、故障恢复和不同 BIOS 版本兼容性记录。
- 物理核验 CPU/GPU 两侧散热通道；当前 UI 命名依据协议与本机曲线实验。

不通过开机重放掩盖固件状态，也不通过写入未知寄存器制造故障。
