# 风扇响应速度候选地址实验

这是诊断模块，不是产品接口。仅支持已测试的 MECHREVO X6xR55xK，候选地址来自本机 Windows 控制中心的 `RamFan1p5_ECSpec.ADDR_TimAP_FanSwitchSpeedT100mSec = 0x0787`。

仅接受 `candidate=3`、`6`、`0x83` 或 `0x86`。后两项根据用户截图中 1–127 的时间范围测试最高位启用假设。要求加载前原值为 0 且 ACPI/WMI 读回一致；使用 WMI 写入并由 ACPI 读回核对。卸载或 180 秒后恢复原值。没有扫描或修改其他候选启用位，没有任意寄存器写入接口。

这些原始值的时间含义属于实验假设，不能仅凭符号名宣称已确认 300/600 ms。需比较相同曲线跃变的实际 PWM 变化率，并核对恢复日志。产品驱动保持不变。

构建需要当前内核头文件；加载需要有效模块签名和 root。正式实验还需保存用户曲线、暂停系统服务避免并发写入、监测温度并在结束恢复配置。验证记录位于 `docs/validation/`。
